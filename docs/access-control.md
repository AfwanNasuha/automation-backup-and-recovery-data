# Access Control

Dokumentasi pengelolaan user, group, dan permission Linux.

Fokus:
1. Identifikasi akun yang berwenang.
2. Pengaturan group.
3. Pembatasan akses direktori backup.
4. Pengujian akses akun berwenang.
5. Pengujian penolakan akses akun tidak berwenang.

Konfigurasi aktual dan bukti pengujian
akan ditambahkan selama implementasi.
