# Data Uji

Direktori ini disiapkan untuk berkas dummy yang digunakan dalam pengujian backup, verifikasi integritas, dan pemulihan.

Ketentuan:
1. Gunakan data buatan, bukan dokumen pribadi atau data asli yang sensitif.
2. Catat jumlah berkas, ukuran total, dan susunan direktori untuk setiap rangkaian pengujian.
3. Pertahankan salinan data acuan agar hasil restore dapat dibandingkan.
4. Jangan menyimpan arsip backup hasil eksekusi di direktori ini. Arsip operasional disimpan pada lokasi backup yang ditentukan saat implementasi.
